- **OS란 무엇인가요?**
    
    운영체제란 컴퓨터 하드웨어와 소프트웨어 사이에서 중개자 역할을 수행하는 시스템 소프트웨어입니다. 운영체제는 메모리, CPU, 저장장치, 입출력 장치와 같은 자원을 관리하며, 다중 프로그램의 실행을 위해 프로세스 스케줄링, 동시성 제어 등의 역할을 수행합니다. 즉, 운영체제는 하드웨어를 추상화하여 애플리케이션이 하드웨어를 다루는 방법을 정의합니다.
    

- **OS의 주요 3가지 특징을 설명해주세요.**
    
    운영체제는 크게 **가상화**, **동시성**, **지속성**이라는 세 가지 핵심 특징을 갖습니다. **가상화**는 CPU, 메모리, 저장장치 등의 하드웨어 자원을 여러 프로그램이 독립적으로 사용하는 것처럼 보이도록 추상화하는 기능으로, 예를 들어 각 프로세스가 자신만의 메모리를 가지는 것처럼 보이게 합니다. **동시성**은 여러 작업이 마치 동시에 실행되는 것처럼 보이도록 스레드나 프로세스를 스케줄링하여 처리하는 능력으로, CPU의 시간을 분할해 빠르게 전환함으로써 이를 구현합니다. 마지막으로 **지속성**은 데이터를 휘발성 메모리가 아닌 저장장치에 영구히 보존할 수 있도록 파일 시스템을 통해 관리하는 능력으로, 전원이 꺼진 후에도 데이터가 유지되도록 보장합니다.
    

- **시스템 콜이 무엇인지 설명해주세요.**
    
    시스템 콜(System Call)은 사용자 프로그램이 운영체제의 커널 기능을 요청할 때 사용하는 인터페이스입니다. 사용자 모드에서 실행 중인 애플리케이션은 직접 하드웨어 자원(CPU, 메모리, 파일 등)에 접근할 수 없기 때문에, 운영체제의 도움을 받아야 하며, 이때 시스템 콜을 통해 커널 모드로 전환하여 필요한 작업을 수행합니다.
    

- **인터럽트와 트랩의 차이를 설명해주세요.**
    - **인터럽트**
        - 실행 흐름을 강제로 멈추고 운영체제가 개입하게 만드는 메커니즘
        - 하드웨어 또는 소프트웨어가 발생시킬 수 있음
        - 현재 CPU가 하던 일을 멈추고 인터럽트 핸들러(Interrupt Handler)를 실행
        - 보통 하드웨어 인터럽트를 의미한다.
    - **하드웨어 인터럽트**
        - 키보드, 마우스, 타이머 등 장치가 CPU에 처리 요청을 보냄
        - 주로 비동기적으로 발생 (프로그램 실행 흐름과 상관없이)
        - 키보드를 누름 → 키보드 컨트롤러가 인터럽트 발생 → CPU가 입력 처리
    - **소프트웨어 인터럽트**
        - 프로그램(소프트웨어)이 의도적 또는 비의도적으로 발생시키는 인터럽트
        - 프로그램 내에서 동기적으로 발생  (현재 실행 중인 명령으로 인해 발생)
        - Trap (의도적), Exception (비의도적)
    - **Trap**
        - 사용자가 커널 서비스를 요청하기 위해 의도적으로 발생시키는 소프트웨어 인터럽트
        - 시스템 콜을 호출할 때 사용됨
        - 트랩 발생 시 운영체제가 개입하여 특정 커널 기능을 실행
    - **Exception**
        - 프로그램 실행 도중 발생한 예기치 않은 오류 상황
        - 0으로 나누기, 잘못된 메모리 접근 등
        - 기술적으로는 예외(Exception)도 Trap으로 처리되지만, 발생 의도를 기준으로 분류할 수 있음

- **커널이 무엇인지 설명해주세요.**
    - 기본적으로 프로그램이 실행되기 위해서는 메모리에 적재된 상태여야 한다.
    - 운영체제 역시 프로그램이기 때문에 메인 메모리에 적재되어야 하나, 운영체제의 크기가 너무 크기에 전부 메모리에 올리기는 어렵다.
    - 따라서 커널이라고 하는 항상 필요한 운영체제의 핵심 부분만을 메인 메모리에 적재하여 운영체제를 사용하게끔 한다.
    - 즉, 커널은 메모리에 상주하는 운영체제의 핵심 부분이다.
